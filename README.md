# Rollcall

> Offline-first attendance and gradebook for trainers running classes where connectivity is bad.

Create your classes and roster, tap through attendance in each session
(present/absent/late/excused), see who's at risk of dropping out, keep a simple
gradebook, and print the A4 report or export CSV — all in the browser, working
offline after first load, no accounts, no keys.

Built one PR per evening by [weekly-lab](https://github.com/topics/weekly-lab) — week 2026-W32.
See `SPEC.md` for the scope and `TICKETS.md` for the plan.
